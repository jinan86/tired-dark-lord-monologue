# The Tired Dark Lord: A 100-Word Villain Monologue

A 100-word monologue for [The Tired Dark Lord: A 100-Word Villain Monologue](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb) on make.fun.

The speaker is no throne-sitting conqueror: four hundred years ago he
chained the god Maw beneath a mountain, and ever since he alone has held
the chain. His exhaustion is never named — it leaks out in a lost count,
a dropped thread, a deflection — and the last line hands the hero the
burden instead of a battle.

## Run it

```sh
python3 main.py            # writes /output/entry.txt
OUTPUT_DIR=./out python3 main.py
```

Python 3.13, standard library only. No network, no randomness, no
secrets — the same 100 words (506 characters) on every run.

## The monologue

> You came up the black stair, past the chalk marks where I count the nights. Four hundred years, and I still lose count at — never mind. I chained the god Maw under this rock when your great-grandfather's sword was new. He sings, down there. He sings my name wrong, on purpose, to pass the time. The chain is cold. It slips. It always slips, and I catch it, and I catch it, and — what was your name? Ah. Yes. You, with the bright sword. Strike, then. But hold the chain while you do. It only knows my hands.
